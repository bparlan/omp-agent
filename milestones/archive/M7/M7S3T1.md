## Test Contract

### Purpose

Verify the implementation of the non-destructive legacy indexing and classification mechanism for the pre-M10 corpus (M1-M9). Tests exercise `bin/legacy_indexer.py` and the `bin/resolve_artifact.py` legacy manifest integration across 12 verification items covering all 6 classification tiers, read-only invariance, safe fallback, coexistence, integrity verification, and performance bounds.

### Execution

Each test is a standalone Bash script that:
1. Creates an isolated fixture directory under `tests/M7/fixtures/`
2. Executes the target script with the verification-defined command
3. Asserts expected evidence (exit codes, file existence, line counts, checksum matches, stderr output)
4. Cleans up the fixture directory on exit

All tests are in `tests/M7/` and named after their verification item.

### Initial State

Tests are expected to fail where `bin/legacy_indexer.py` does not yet exist or `bin/resolve_artifact.py` lacks legacy manifest integration. These are `VALID_INITIAL_FAILURE` — the test exercises the intended subject, and failure correctly indicates missing implementation.

### Post-Implementation State

All implementation verification tests are expected to pass. Specification checks (DOCUMENT_CHECK) are not in this test set — all 12 verification items are SCRIPT_EXECUTION.
