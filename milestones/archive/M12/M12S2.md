#### Objective
Create the operational governance skill `manage-docs` for the AEF SDD pipeline. This skill governs the `docs/` folder through an intake buffer (`docs/queue/`), folder governance rules for `docs/hotfixes/`, `docs/diagrams/`, `docs/solutions/`, and official `docs/*.md`, event-driven new-file detection for `docs/`, and registration of the `operations-consolidation` artifact type. This specification does not modify existing `docs/` contents and does not touch tactical pipeline artifacts beyond reading closure artifacts for cross-referencing.

##### Milestone Complexity & Multi-Spec Plan
M12 is decomposed into three sequential specifications:
- **M12S1** — Behavioral-Vector Persona Overhaul for `manage-development` (completed).
- **M12S2** — `manage-docs` Skill Creation (this specification).
- **M12S3** — Handoff Contracts and Cross-Skill DevOps Cycle Integration.

Only M12S2 scope is addressed below.
