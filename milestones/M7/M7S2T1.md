## Test Contract

### Purpose

Verify the artifact resolution and canonical storage implementation for M7S2. Tests exercise `bin/resolve_artifact.py` against isolated fixture directories, verifying the 3-tier priority resolution (FR-7), conflict detection (FR-8), dual query support (FR-9), read-only operation (NFR-2), performance bound (NFR-3), portable path resolution (NFR-4), and the formalized canonical directory structure contract in `docs/ARTIFACT_ARCHITECTURE.md` (FR-6, FR-10).

### Execution

```bash
# Run all tests individually
bash tests/M7/test_resolve_canonical_id.sh
bash tests/M7/test_resolve_legacy_id.sh
bash tests/M7/test_resolve_conflict_detection.sh
bash tests/M7/test_resolve_not_found.sh
bash tests/M7/test_resolve_readonly.sh
bash tests/M7/test_resolve_artifacts.sh
bash tests/M7/test_artifact_architecture_docs.sh
```

Tests are designed as SPECIFICATION_CHECK (DOCUMENT_CHECK items) and IMPLEMENTATION_CHECK (SCRIPT_EXECUTION items).

### Initial State

Tests are expected to fail only where the implementation is not yet present:
- Script execution tests (V-FR-7a, V-FR-7b, V-FR-8, V-FR-9, V-NFR-2, V-NFR-3, V-NFR-4) will fail with VALID_INITIAL_FAILURE because `bin/resolve_artifact.py` does not exist yet.
- DOCUMENT_CHECK tests (V-FR-6, V-FR-10) will fail with VALID_INITIAL_FAILURE because `docs/ARTIFACT_ARCHITECTURE.md` has not been updated with the formalized contract.

### Post-Implementation State

All implementation verification tests are expected to pass. `bin/resolve_artifact.py` will exist and correctly implement the 3-tier resolution. `docs/ARTIFACT_ARCHITECTURE.md` will contain definitive specification language for the canonical directory structure.
