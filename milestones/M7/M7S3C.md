#### 3. Technical Changes Summary

**bin/legacy_indexer.py** — 6-tier classification fallback implementation:

| Tier | Method | Implementation |
|------|--------|---------------|
| 1 | YAML frontmatter | Parses `type` or `id` fields via `_frontmatter.extract_frontmatter()`. Handles UnicodeDecodeError for binary files. |
| 2 | Directory structure | Infers type from parent directory name (e.g., `specifications/` → `specification`). |
| 3 | Top-level Markdown headers | Reads first line, matches `# Specification`, `# Investigation`, etc. |
| 4 | Legacy filename naming | Regex `M{X}S{Y}[SUFFIX][N].md` with suffix mapping (V→verification, T→test_set, C→completion, etc.). |
| 5 | Custom pattern mapping | Loads external `<filename>:<type>` mapping file via `--pattern-map`. |
| 6 | Human review | Falls through to `AMBIGUOUS_LEGACY_ARTIFACT` with stderr flagging. |

Handles `--milestone-dir` pointing to either a parent directory (containing M1-M9 subdirs) or directly to an M1-M9 directory.

**bin/resolve_artifact.py** — Added `resolve_legacy_manifest()` function that searches for `legacy_manifest.txt` at three candidate paths:
1. `{base_dir}/legacy_manifest.txt`
2. `{base_dir}/milestones/{milestone_id}/legacy_manifest.txt`
3. `{milestone_dir}/legacy_manifest.txt`

Called as Tier 4 fallback after Tier 3 filename heuristics produce no match.

#### 4. Edge Cases Handled

- **Binary files** (`.DS_Store`, `.bin`): `UnicodeDecodeError` caught in Tier 1 (frontmatter) and Tier 3 (heading) classification, falling through gracefully to Tier 6.
- **Non-M1-M9 directories**: Skipped with optional verbose message.
- **`--milestone-dir` pointing directly to M1-M9 directory**: Handled via fallback scan when no subdirectory entries found.
- **Files without YAML frontmatter, directory context, or heading**: Classified via Tier 4 (legacy filename) or Tier 6 (AMBIGUOUS_LEGACY_ARTIFACT).
- **Empty or corrupted manifest**: `resolve_legacy_manifest()` gracefully returns `None, None` on IOError or missing manifest.
- **`AMBIGUOUS_LEGACY_ARTIFACT` entries in manifest**: Explicitly skipped during resolution (not a valid target).

#### 5. Identified Technical Debt

- **Test assertion bugs**: Three tests have incorrect expectations that should be corrected by the test generator:
  - Path offset off-by-one in `test_legacy_manifest.sh`
  - Manifest content expectations in `test_classify_tier1_frontmatter.sh` (checking for `id` that doesn't appear in manifest)
  - `time` command redirection in `test_performance_bound.sh`

- **Pattern map file format not validated**: `load_pattern_map()` accepts any `filename:type` pair without validating the type against known artifact types.
