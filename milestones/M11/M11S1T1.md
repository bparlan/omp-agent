## Overview

This test plan translates the VER-M11S1V evidence contracts into executable test scripts for the Environment / Reproducibility Layer. All tests assert observable runtime behavior against the CLI, schema, and fixture contracts declared in SPEC-M11S1.

## Test Strategy Notes

- **YAML parsing** is performed exclusively with Python's `yaml` library (via pytest). Bash scripts MUST NOT use `grep "name:"` or other substring matching against YAML fixture text.
- All `.sh` scripts invoke the target CLI binary directly (e.g., `env-check ...`) with no interpreter prefix and no pre-flight existence check, so the natural `exit 127` is the valid pre-implementation failure.
- Schema validation tests parse `milestones/M11/environment-schema.json` and `test_fixtures/*.yml` as structured data, asserting positive presence of required keys.
