#### Expected Coverage

**Functional Validation:**
- **FR-1 (lbug CLI):** Test script verifies CLI version output and PATH accessibility
- **FR-2 (Python client):** Test script verifies import success and version detection
- **FR-3 (graph-context skill):** Test script verifies SKILL.md existence, injectability documentation, and schema specification
- **FR-4 (Graph schema):** Test script creates test project, runs injection, validates File, Symbol, IMPORTS types only
- **FR-5 (skeleton.md parser):** Test script creates sample skeleton.md, runs parser, validates node counts and edge creation
- **FR-6 (verification hook):** Test script creates test task, modifies in-scope/out-of-scope files, verifies pass/fail behavior
- **FR-7 (BariaDAO pilot):** Test script navigates BariaDAO, runs init/ingest, validates graph population and queryability

**Edge Cases Covered:**
- Empty skeleton.md (parser should handle gracefully)
- Single file project (graph should have correct node/edge counts)
- Circular imports (parser should handle without errors)
- Deeply nested imports (parser should resolve correctly)
- Non-Python import syntax (parser should not crash)

**Failure Scenarios Covered:**
- Out-of-scope edit passing verification (gate failure)
- In-scope edit failing verification (false positive)
- Graph file not created (permission errors)
- Parser crashing on unresolved imports
- lbug command not found (PATH issue)

**Regression Checklist Covered:**
- graph-context SKILL.md completeness
- generate-verification skill compatibility
- AEF environment conflicts
