#### Test Environment

- **Testing Framework:** Bash shell scripts (POSIX-compatible)
- **Setup Requirements:** Standard Unix utilities (test, grep, head, tail, sed, awk, cut, which, git). The ground-truth script tests require `bin/ground-truth-check.sh` to exist (created by implementation). No external dependencies, mock databases, or environment variables needed.

---

#### Executable Scripts Generated

- `tests/M3/test_uncertainty_marker.sh` — FR-1: Verifies `#NEEDS-CLARIFICATION` marker exists in docs/FRAMEWORK.md, AGENTS.md, and skills/implement-specification/SKILL.md with correct positioning and HALT-on-guessing rule.
- `tests/M3/test_zero_trust_review.sh` — FR-2: Verifies review-implementation/SKILL.md has the zero-trust standing rule and review_template.md has the Live State Verification section with claim/command/observed-state fields.
- `tests/M3/test_evidence_debugging.sh` — FR-3: Verifies investigate-issue/SKILL.md and evaluate-implementation/SKILL.md begin with "Debug from evidence, never from memory" including anti-pattern-matching clause and `--help`/introspection mention.
- `tests/M3/test_raw_evidence_mandate.sh` — FR-4: Verifies completion_template.md and evaluation_template.md have a "## Raw Evidence" section with "exact terminal command"/"raw output" language and structured bullet template.
- `tests/M3/test_ground_truth_helper.sh` — FR-5: 15-test suite exercising all 5 ground-truth commands (file-exists, dir-exists, command-exists, file-contains, git-status) with correct PASS/FAIL exit codes, plus write-operation audit and header documentation check.
- `tests/M3/test_tooling_stack.sh` — FR-6: Verifies bootstrap-project/SKILL.md and AGENTS.md have all 4 tooling categories (Environment Manager, Fast Linter/Formatter, Pre-commit Framework, Type Checker), correct step positioning, and no hardcoded brand names.
- `tests/M3/run_all_m3s2_tests.sh` — Master test runner executing all 6 FR test scripts and reporting summary.

---

#### Expected Coverage

- **Functional Validation:** All 6 FRs covered (FR-1 through FR-6).
- **Edge Cases Covered:**
  - Ground-truth script: non-existing paths, non-existing commands, non-matching patterns, non-git directories, no-args crash safety, `--help` output, write-operation audit
  - Uncertainty marker: correct section positioning between SDD and Agent-Tool Separation
  - Zero-trust review: correct section ordering (Compliance < Live State < Architecture Assessment)
  - Tooling stack: brand name audit (15 known brands checked)
- **Failure Scenarios Covered:**
  - Missing marker in any target file
  - Rule placed after other content instead of beginning of file
  - HALT/stop requirement softened or absent
  - Write operations present in ground-truth script
  - Hardcoded brand names in tooling mandate
  - Tooling categories missing or incomplete
