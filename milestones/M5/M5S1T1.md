**Mock RepairLoopTracker:**

```python
class RepairLoopTracker:
    def __init__(self, max_cycles=3):
        self.max_cycles = max_cycles
        self.counter = 0

    def increment(self):
        self.counter += 1

    def get_count(self):
        return self.counter

    def reset(self):
        self.counter = 0

    def check_limit(self):
        return self.counter < self.max_cycles
```
