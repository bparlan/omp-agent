#### Validity Metadata

**Subject under test:** The validity gate as defined in `skills/evaluate-implementation/SKILL.md` and `skills/generate-tests/SKILL.md`. These tests validate the *concept* of the validity gate — they simulate what the gate should do when implemented.

**Acceptance criteria for validity:** Each meta-test is valid when:
- It exercises a specific validity criterion (self-scan, wrong path, subject existence, clean tree, exit code 2)
- Its failure is attributable to the absence of the validity gate implementation, not to environment or infrastructure
- It is deterministic — same inputs produce same results
- It does not scan its own source (by design)
- It produces diagnostic failure messages

**Expected failure conditions:** All 5 meta-tests are expected to initially FAIL (pre-implementation state) because the validity gate instructions have not yet been implemented in the skill files.

**Environment prerequisites:**
- `bash` — required for script execution
- `git` — required for Test K (dirty tree detection)
- Codebase root — scripts `cd` to project root for M7 regression checks
