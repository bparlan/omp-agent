# Test Design Ledger: Canonical Artifact Identity & Lineage Contract

## Test Contract

### Purpose

Validate the `bin/omp-verify-metadata` CLI tool against the YAML frontmatter schema defined in SPEC-M10S2. Tests cover tool existence, CLI argument handling, schema validation (required fields, types, enum values), semantic qualifier rejection, non-existent path handling, and files without frontmatter.

### Execution

Each test is a standalone Bash script executed via `bash <test_file>`. Tests assert against exit codes only — no prose matching. All tests source static fixtures from `tests/fixtures/synthetic_metadata_valid/` and `tests/fixtures/synthetic_metadata_invalid/`.

### Initial State

The tool `bin/omp-verify-metadata` does not yet exist. Implementation tests are expected to fail with `VALID_INITIAL_FAILURE` (exit code 127 for command not found, or exit code 1 if the tool exists but lacks required behavior).

### Post-Implementation State

All implementation verification tests are expected to PASS.
