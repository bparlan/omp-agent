# Hotfix Report: No Prose Contracts Enforcement

**Date:** 2026-08-03
**ID:** HF_20260803_001
**Status:** Completed

## Summary

This hotfix implemented a mechanical gate to enforce the 'No Prose Contracts' rule, ensuring that verification artifacts are not written using prose-based verification methods. A linter script was created, integrated into core skills, and tested.

## Checklist Items Addressed:

1.  **Create `bin/lint-verification-contract.sh`**: A script was created to scan verification artifacts for forbidden patterns (`grep`, `text search`, `text-match`, `text matching`) case-insensitively, skipping lines tagged `<!-- ALLOWED: literal-boilerplate -->`. It exits non-zero with offending lines if found untagged, and 0 otherwise. The script was made executable.
2.  **Update `generate-verification/SKILL.md`**: The skill was updated to include a mandatory linting gate after generating criteria. If the linter fails, the skill must revise and re-run, and cannot proceed to `generate-tests`.
3.  **Update `generate-tests/SKILL.md`**: The skill's preconditions were updated to re-run the same linter independently against the verification artifact as its own entry check.
4.  **Test Linter Script**: Two synthetic fixtures (`verification_fixture_fail.md` and `verification_fixture_pass.md`) were created and tested with the linter. The raw output demonstrated correct failure and pass behavior.

## Out of Scope:

No changes were made to `milestone`, `generate-spec`, or `implement-specification`. No full Downstream Generation Contract was built.
